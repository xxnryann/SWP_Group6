📅 Ngày: 2026-11-04
✅ Trạng thái: Hoàn thành

───────────────────────────────────────────────────────────────────
  TÍNH NĂNG MỚI
───────────────────────────────────────────────────────────────────

✨ 1. LỐI ĐI BÊN PHẢI
   • Hiển thị lối đi dọc màu xám với nhãn "LỐI ĐI"
   • Nằm giữa hàng ghế và nút "Đổi loại"
   • Tự động thu gọn trên màn hình nhỏ
   • Không ảnh hưởng chức năng ghế

✨ 2. GHẾ MẶC ĐỊNH MÀU XÁM KHI TẠO PHÒNG
   • Loại ghế mới: "Unassigned" (chưa chọn loại)
   • Tất cả ghế mặc định là Unassigned (xám)
   • Admin phải chọn loại ghế sau khi tạo phòng
   • Dropdown hiển thị "Chọn loại ghế"

✨ 3. MÀU SẮC THEO LOẠI GHẾ
   🔲 Unassigned (chưa chọn)  → Xám nhạt
   🟢 Standard (ghế thường)   → Xanh lá
   🟡 VIP                     → Vàng/Cam
   💗 Couple (ghế đôi)        → Hồng (2 ghế gắn liền)

───────────────────────────────────────────────────────────────────
  CÀI ĐẶT
───────────────────────────────────────────────────────────────────

BƯỚC 1: Chạy SQL Script
────────────────────────
cd SWP_Group6-feature-cinema-full-update
sqlcmd -S "tcp:localhost,1433" -U sa -P 123 -d CinemaWebDB ^
  -i database\add_unassigned_seat_type.sql

BƯỚC 2: Restart Server
────────────────────────
• Stop Tomcat
• Clear cache (nếu có)
• Start Tomcat

BƯỚC 3: Test
────────────────────────
1. Đăng nhập Admin
2. Tạo phòng mới
3. Thiết lập layout → Tất cả ghế màu xám
4. Đổi loại ghế → Màu thay đổi tự động

───────────────────────────────────────────────────────────────────
  HƯỚNG DẪN SỬ DỤNG
───────────────────────────────────────────────────────────────────

🎬 TẠO PHÒNG MỚI VỚI LAYOUT GHẾ
─────────────────────────────────
1. Admin → Quản lý phòng → Thêm phòng mới
2. Nhập: Tên phòng, Loại (2D/3D), Sức chứa
3. Lưu phòng

4. Vào "Layout ghế" → Nhập số hàng & số ghế/hàng
5. Bấm "Áp dụng layout"
   ✓ Tất cả ghế hiển thị màu xám (Unassigned)
   ✓ Có lối đi dọc bên phải

🎨 ĐỔI LOẠI GHẾ
─────────────────────────────────
Mỗi hàng ghế có dropdown "Chọn loại ghế":

• Standard  → Ghế thường (xanh lá)
• VIP       → Ghế VIP (vàng/cam), giá cao hơn
• Couple    → Ghế đôi (hồng), đặt theo cặp

Sau khi chọn → Bấm "Đổi loại" → Màu tự động thay đổi

⚠️ LƯU Ý ĐỔI SANG COUPLE:
   ✓ Số ghế phải CHẴN (2, 4, 6, 8, 10...)
   ✓ Đánh số liên tục từ 1
   ✓ Không có ghế đang bảo trì
   ✓ Ghế tự động ghép cặp: 1-2, 3-4, 5-6...

───────────────────────────────────────────────────────────────────
  DEMO HIỂN THỊ
───────────────────────────────────────────────────────────────────

              🎬 MÀN HÌNH 🎬

A  [A1] [A2] [A3] [A4] [A5]  │     │  [Chọn loại ▾] [Đổi loại]
                               │ L   │
B  [B1] [B2] [B3] [B4] [B5]  │ Ố   │  [Standard  ▾] [Đổi loại]
                               │ I   │
C  [C1] [C2] [C3] [C4] [C5]  │     │  [VIP       ▾] [Đổi loại]
                               │ Đ   │
D  [D1═D2] [D3═D4] [D5═D6]   │ I   │  [Couple    ▾] [Đổi loại]
                               │     │

Chú thích:
• [A1] xám      = Unassigned (chưa chọn)
• [B1] xanh     = Standard
• [C1] vàng     = VIP
• [D1═D2] hồng  = Couple (gắn liền)

───────────────────────────────────────────────────────────────────
  TROUBLESHOOTING
───────────────────────────────────────────────────────────────────

❌ Ghế vẫn màu xanh thay vì xám?
   → Chạy lại SQL script
   → Xóa cache browser (Ctrl + F5)
   → Restart Tomcat

❌ Không đổi được sang Couple?
   → Kiểm tra số ghế phải chẵn
   → Không có ghế đang bảo trì
   → Ghế đánh số liên tục từ 1

❌ Lối đi đẩy nút ra ngoài màn hình?
   → Responsive tự động xử lý
   → Thu nhỏ cửa sổ browser để test
